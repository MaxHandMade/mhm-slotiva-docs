Slotiva 1.0.3 is a maintenance release. If you have already set up a bookable product, the most important change is that running
the setup wizard again no longer touches that product's own settings.

<!-- truncate -->

## Fixed

- **Running the setup wizard again keeps your product's settings.** An existing bookable product keeps its own appointment length,
  minimum hours per order and pricing. Step 3 tells you when the product keeps its own length, and the customer preview and the
  summary show that length. See [Setup wizard](/docs/getting-started/setup-wizard#step-3).
- **The summary always shows your service type**, also when you kept the suggested type without clicking a card.
- **One limit for the appointment length: 480 minutes (8 hours).** It applies everywhere you can set a length — the setup wizard,
  Slotiva → Working hours and the product's Slotiva tab. If a longer length was saved earlier, it does not stop you from saving
  your other working-hours settings. The wizard also refuses a price that is not a valid number.
- Activating Slotiva in a way that cannot open the setup wizard (for example from the command line or network-wide) no longer
  leaves an older "open the wizard" note behind that would send you to the wizard later.

## Changed

- **License screen:** the same views and texts as before, now with a help link under every state once a key is entered. The update hint names the
  current WordPress menu: **Plugins → Add Plugin → Upload Plugin**.
- **Slotiva → Settings → Bookable products** now says **Per slot** instead of "Per hour", the same as the product's Slotiva tab.
- **The payment check in the setup wizard** now says where to turn a payment method on: WooCommerce → Settings → Payments.
- Turkish admin texts now use the same informal voice everywhere.

## Added

- **Help links to this documentation:** **First-time setup guide** at the end of the setup wizard, **How to fix** on every
  checkout-check row that needs attention, and **About this license status** on the License screen. Admins who use WordPress in
  Turkish get the Turkish pages.

## Updating

Download 1.0.3 from your account and install it via **Plugins → Add Plugin → Upload Plugin** — see
[Updating](/docs/getting-started/installation#updating). Your appointments, working hours and settings are kept.
